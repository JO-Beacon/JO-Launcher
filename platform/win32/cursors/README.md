The three cursor files in this directory are copied from Chromium:

- Source: https://github.com/chromium/chromium/tree/main/ui/resources/cursors
- Files: `pan_middle_vertical.cur`, `pan_north.cur`, `pan_south.cur`
- License: BSD 3-Clause, Copyright 2015 The Chromium Authors
- Full license text: `third_party/licenses/chromium-BSD-3-Clause.txt`

They are used only for the middle-click autoscroll cursor. Do not add Chromium
branding or logos to the application.
