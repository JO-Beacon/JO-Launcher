01 / 功能

启动所需的全部，没有多余打扰。

为已经拥有 Minecraft: Java Edition、想要一个安静桌面客户端的玩家准备的一组专注工具。

01

版本识别

扫描 versions/，识别 vanilla、Fabric、Quilt、Forge 与 NeoForge 安装。

02

按版本设置

Java 路径、内存上限与 JVM 参数保存在各版本目录里的 jolauncher.json。

03

启动工作台

选一个版本，启动与停止游戏，并在同一屏里跟进实时日志。

04

微软登录

通过设备码流程登录你自己的微软账号，Azure 应用（客户端）ID 由你提供。

05

桌面界面

深色、浅色与跟随系统主题，可拖动的侧栏，十种界面语言。

06

本地账号数据

令牌保存在本地受 Windows DPAPI 保护的文件中。没有后端，没有遥测；可在设置里删除账号数据。

02 / 为什么选 JO-Launcher

为你已经装好的那套游戏而做。

JO-Launcher 不下载、也不分发游戏。把它指向一个已有的 .minecraft 目录，启动里面已经装好的版本。

致力于成为一个专注的客户端：启动快、界面小、没有后台服务、没有广告，也不做多余的数据收集。

  • 不捆绑游戏文件
  • 没有账号后端与遥测
  • 开源可审计
  • 账号数据可在应用内删除

03 / 路线图

接下来做什么。

Linux 支持与多账号切换在计划中。登录、版本管理、导入与清理已经可用。

可用版本管理从版本页导入文件夹或 zip，重命名、删除版本。
计划中Linux 桌面同一套原生代码的第二个桌面目标。
可用微软登录设备码登录，使用你自己的 Azure 应用（客户端）ID。头像与多账号切换在计划中。
计划中崩溃诊断更清晰的失败报告与恢复路径。
