# Contributing

## Issues are welcome

Bug reports and feature requests are handled through GitHub Issues.

When opening an issue, please include:

- JO-Launcher version
- Windows version
- Steps to reproduce
- Expected and actual behavior
- Relevant logs, with tokens, account names and email addresses removed

## Pull requests are not accepted

This repository does not accept pull requests. Please do not open one; pull requests are closed automatically.

If you want to suggest a code change, open an issue first and describe the problem and the proposed approach.
